## 2026-10-24 · No.03·06 야구
- 피드백: 의도는 '야구는 왜 재밌을까'를 '불확실성이 높아서'라는 관점으로 해석하는 글. No.03 표지 '왜 이렇게 불확실할까'는 그럭저럭, No.06 '왜 이렇게 예측이 어려울까?'는 질문 자체가 바뀜. 질문은 주는 대로 그대로 제목으로.
- 진단: 질문 이해 — 부연(관점)을 핵심 질문으로 착각해 질문을 바꿔 씀. 표지 제목을 Claude가 자유롭게 지은 것도 원인.
- 반영:
  - `prompts/guidelines.md` › 내용 › 질문 이해 › ' - ' 앞은 핵심 질문, 뒤는 관점. 관점으로 핵심 질문에 답하고 질문을 바꾸지 않음 / 표지 제목은 핵심 질문 그대로
  - `src/pipeline.js` › 표지 제목을 Claude 원고 대신 질문 칸의 ' - ' 앞부분으로 고정
  - `src/render.js` › 표지 제목이 3줄을 넘으면 글자 크기 자동 축소
  - `src/research.js` › 원고 스키마 표지 제목 설명을 '질문 그대로'로 수정

- 반영:
  - `prompts/guidelines.md` › 내용 › 원고 구성 › '왜' 질문은 여러 설명을 근거 강한 순으로, 결론도 여러 요인을 묶어서
  - `prompts/guidelines.md` › 내용 › 원고 구성 › 사례·실험은 무엇을 확인한 것인지 먼저 한 문장으로
  - `src/research.js` › 검증된 출처 3개 미만 또는 답할 수 없으면 범위를 넓혀 한 번 더 조사, 그래도 부족하면 게시 보류(Notion 상태 '보류')
