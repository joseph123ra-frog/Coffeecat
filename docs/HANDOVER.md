# Coffeecat 인수인계
기준일: 2026-11-07 (한국시간). 사용자 인수인계와 저장소 확인 결과를 구분해 기록합니다.

## 사용자와 작업 원칙
- 사용자는 개발자가 아닙니다. 한국어로 짧게, 핵심만 설명합니다. 직접 해야 하는 일은 최소화하고 한 단계씩 안내합니다.
- 요청이 모호하면 작업 전에 질문합니다. 모르는 정보는 지어내지 않고 "신뢰할 수 있는 데이터 없음"으로 표시합니다.
- 인용 정보는 출처 링크를 열어 내용까지 확인합니다. 확인하지 못한 범위는 밝힙니다.
- 토큰·API 키를 채팅으로 받거나 코드·문서·로그에 기록하지 않습니다. 사용자가 GitHub Secrets에 직접 입력하게 안내합니다.
- 확정된 디자인·운영 결정을 바꾸기 전에 사용자에게 묻습니다.

### 변경 전에 확인할 확정 사항
- 8장: 질문을 그대로 쓰는 표지 / 본문 6장(사진 70%, 흰 공간 30%) / 고정 시그니처.
- 질문 칸의 ' - ' 앞은 핵심 질문이자 표지 제목, 뒤는 답할 관점입니다. 표지는 물음표를 자동 처리합니다.
- 사진: Unsplash → Wikimedia → 없으면 웃긴 고양이 사진. 글은 유지합니다. AI 생성 이미지는 금지합니다.
- Pexels는 사용자 설명상 신규 키 발급 중단으로 미사용입니다. 기존 문서·워크플로에 선택 항목이 남아 있어도 임의 활성화하지 않습니다. 외부 서비스의 현재 정책은 이번 인수인계에서 재확인하지 않았습니다.
- 캡션: 첫 줄 검색어+질문 / 바로 다음 줄 단서(중간 빈 줄 없음) / 출처 한 문장 / 사진 사이트명 / 주제 해시태그 4개 + #깝휘캣 / 고지 문구 맨 끝.
- 고지: *해당 콘텐츠는 AI의 조사만을 거친 게시물로, 내용에 오류가 있을 수 있습니다
- 출처 3개 미만 등 근거 부족이면 범위를 넓혀 한 번 더 조사하고, 그래도 부족하면 게시 보류(Notion 상태 '보류').

### 확인한 현재 상태
- `data/usage.json`의 issue는 8입니다. 다음 호수는 항상 최신 issue + 1로 정합니다.
- 장부에는 2026-10 비용 $3.786, runs 11이 기록돼 있습니다. 11월 기록은 없습니다. 기록 부재를 외부 API의 실제 비용 0으로 단정하지 않습니다.
- archive 루트에는 No.02~08 기록이 있고 No.01 원고 기록은 없습니다. 피드백 기록에도 No.01 게시 기록 부재가 명시돼 있습니다.
- 최신 No.08 파일은 2026-10-27, 질문은 "왜 한국 아파트 이름은 점점 길어질까?"입니다. 게시 URL이 기록돼 있으나 이번에는 Instagram 원문이나 기사 출처를 검증하지 않았습니다.
- 최근 자동 게시 실행 5건은 GitHub상 success입니다. 최신은 2026-11-07 09:50 KST 실행입니다: https://github.com/joseph123ra-frog/Coffeecat/actions/runs/42320625844
- 워크플로 성공에는 게시를 건너뛴 경우도 포함될 수 있습니다. 성공 표시만으로 새 게시물 발행이나 모든 외부 연동의 정상 상태를 단정하지 않습니다.

### Secrets와 제약
- 사용자 설명상 등록 완료: ANTHROPIC_API_KEY, NOTION_TOKEN, NOTION_DATABASE_ID, IG_USER_ID, IG_ACCESS_TOKEN, UNSPLASH_ACCESS_KEY, SECRETS_PAT.
- 비밀값 자체와 현재 유효성은 이번 확인에서 읽거나 검증하지 않았습니다. Claude 계정 변경만으로 GitHub Secrets를 교체할 필요는 없습니다.
- 이전 Claude Code 클라우드 환경에서는 Meta·Notion·Unsplash 접근이 막혀 있어 실제 호출을 GitHub Actions에서 수행했습니다. 새 환경에서도 필요 시 접근 여부를 확인하며 비밀값을 노출하지 않습니다.
- Instagram API 게시물 삭제·수정 불가는 사용자 인수인계 기준입니다. 삭제는 사용자가 앱에서 합니다. 이번에는 Meta의 최신 API 정책을 재검증하지 않았습니다.
- `refresh-token.yml`은 매월 2일·16일 03:00 KST에 토큰을 갱신하도록 설정돼 있습니다. SECRETS_PAT 만료 시 Secrets 교체가 중단됩니다.
- 재게시용 Actions artifact 보관은 사용자 설명상 1일입니다. 오래된 artifact를 사용할 수 있다고 가정하지 않습니다.
- 이 저장소의 Pages는 매 게시물 이미지 배포 때 덮어써집니다. 게임을 여기에 배포하지 않습니다.

### 남은 일
- 사용자가 Instagram 인사이트(도달 수·비팔로워 비율·유입 경로)를 제공하면 릴스 추가나 주제 조정을 판단합니다. 현재 노출 성과는 신뢰할 수 있는 데이터 없음.

- 본 문서를 기본 브랜치에 커밋합니다. 자동 게시나 유료 API 호출을 수동 실행하지 않습니다.
